# 🚀 ROC Web UI (`roc-webui`)

Source Repository: [https://github.com/ivansslo/roc-webui](https://github.com/ivansslo/roc-webui)

## Overview
ROC Web UI is the primary web-based control panel and fleet telemetry dashboard for the ROCAgents ecosystem.

## Key Features
- Live Telemetry & Control Dashboard
- Real-Time WebSocket & SSE Progress Tracking
- Fleet Operations & Node Health Monitoring
- Synchronized Workspace App Management

## Integration
Integrated into `roca-codex` as a primary workspace application. Archive package: `roc-webui.zip`.
